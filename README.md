# 💻 Desenvolvimento Web

Repositório dedicado aos projetos, exercícios e atividades desenvolvidos durante as aulas de **Tecnologia em Análise e Desenvolvimento de Sistemas (TADS)**.

Aqui compartilho minha evolução no desenvolvimento web, colocando em prática conceitos de programação, estruturação de páginas e lógica de programação por meio de atividades práticas.

## 📚 Projetos desenvolvidos

### 🔁 HTML FOR E WHILE
Exercícios práticos de lógica de programação utilizando estruturas de repetição para executar tarefas de forma automatizada.

**Conteúdos praticados:**
- Estruturas de repetição `for` e `while`
- Contadores e condições
- Lógica de programação

[📂 Acessar projeto](https://github.com/Game1254y/DesenvolvimentoWeb/tree/main/HTML%20FOR%20E%20WHILE)

### 🍽️ Restaurante Web
Projeto de desenvolvimento web com temática de restaurante, aplicando conceitos de criação e organização de páginas.

**Objetivos:**
- Praticar a estruturação de páginas web
- Desenvolver interfaces utilizando tecnologias web
- Aplicar os conhecimentos adquiridos em aula

[📂 Acessar projeto](https://github.com/Game1254y/DesenvolvimentoWeb/tree/main/Restaurante%20Web)

### 🔀 Switch Case
Exercícios de lógica de programação utilizando a estrutura condicional `switch case` para trabalhar com diferentes possibilidades de execução.

**Conteúdos praticados:**
- Estruturas condicionais
- Tomada de decisões
- Organização de condições e alternativas

[📂 Acessar projeto](https://github.com/Game1254y/DesenvolvimentoWeb/tree/main/Switch%20case)

## 🛠️ Tecnologias e conceitos

- Desenvolvimento de páginas web
